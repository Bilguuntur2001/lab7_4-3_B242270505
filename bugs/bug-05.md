# BUG-05: API: буруу JSON биетэй POST /api/books хүсэлтэд 400 биш "200 OK" амжилт буцаана

Орчин:  Уншлагын жагсаалт v2.0, Chromium 159.0.8154.6 (Playwright), macOS 26.6.2, 2026-11-25
Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном), http://localhost:3000 нээсэн (браузер шаардлагагүй, `curl`)

## Дахин гаргах алхам
1. Терминал дээр:
   ```
   curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d 'буруу оролт'
   ```
2. Статусын мөр болон биеийг харна.
3. `curl -i localhost:3000/api/books`-ээр жагсаалтыг шалгана.

**Хүлээгдэж байсан:** «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана.»
**Бодит үр дүн:** `HTTP/1.1 200 OK`, бие нь `{"result":"OK"}`. Ном нэмэгдээгүй (жагсаалтад 3 ном хэвээр) ч клиент амжилттай болсон гэж ойлгоно. Нэмэлт: хоосон объект `{}`-ийг `201 Created`-ээр хүлээж авдаг (session 21:08:33, evidence/session-empty-obj.txt).

**Ноцтой байдал:** Major. Клиент алдааг огт мэдэж чадахгүй тул өгөгдөл чимээгүй алдагдана. API-ийн гэрээ (contract) зөрчигдсөн.
